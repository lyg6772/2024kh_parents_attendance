### 검증 순서와 결과

부채가 있는 레포이므로 "0건"이 아니라 **기준선 대비 증가분 0**이 통과 기준이다
(`codebase-conventions.md` § 린트 부채 — 기존 부채는 비차단으로 내리고 새 부채는 막는다).

| 순서 | 검사 | 명령 | 기준선 | 결과 | 판정 |
|---|---|---|---|---|---|
| 1 | 린트 | `poetry run ruff check .` | 93 | **93** | 증가 0 |
| 2 | 포맷 | `poetry run ruff format --check .` | 26 파일 | **26 파일** | 증가 0 |
| 3 | 타입 | `poetry run pyright app` | 25 | **25** | 증가 0 |
| 4 | 테스트 | `poetry run pytest -q` | 242 | **282 passed** | 신규 40, 회귀 0 |

신규 파일 자체는 `ruff check` clean + `ruff format` 적용 완료 — **부채에 보태지 않았다.**
`pyright` 는 이 레포 규약상 `app` 만 보므로 `tests/` 는 그 명령의 대상 밖이다.

### e2e 실기동 (§2-1)

**생략하지 않았다.** `tests/test_http_socket.py` 는 `lifespan="off"` 로 띄우므로 그것과
별개로 **실제 uvicorn + lifespan** 으로 1회 기동해 확인했다:

```
GET /                 -> 200
GET /login            -> 200
GET /attendee         -> 200
GET /admin/attendee   -> 307  Location: /login
lifespan 정상 종료
```

프로브 스크립트는 회귀 자산이 아니므로 실행 후 삭제했고 트리에 남기지 않았다
(`04-test-generation.md` §1 — 실기동은 자산이 아니다).

**마이그레이션 정합성·롤백 왕복: 해당 없음.** DB 스키마 변경이 없다.

**신규 코드 커버리지 게이트: N/A.** 커버리지 도구가 설치돼 있지 않다
(`codebase-conventions.md` § 없는 것 이 소유).

**관측 방출 확인: N/A.** 런타임 표면이 없는 변경이다 (테스트·문서). 다만 이 작업의
산출물 자체가 관측 장치다 — `tests/test_http_env.py` 가 취약 패키지 실행 프레임을 세어
"오라클이 무엇을 덮는지"를 실행으로 남긴다.
