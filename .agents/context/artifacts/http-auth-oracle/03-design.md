### 비즈니스 규칙 (§3-1)

이 작업은 앱 규칙을 만들지 않는다. 대신 **오라클이 고정할 앱의 현행 규칙**을 적는다 —
이것이 테스트의 계약이다.

| # | 규칙 | 근거 |
|---|---|---|
| R-1 | 토큰 없이 인증 라우트 요청 → **307 `Location: /login`** (401 아님) | `app/main.py` 의 401 예외 핸들러가 `RedirectResponse`. 실측 |
| R-2 | 유효 토큰 → 해당 라우트의 정상 응답 | |
| R-3 | 만료·위조·쓰레기 토큰 → **HTTP 층에서 전부 R-1 과 같게** 관측된다 | 실측. 구별하려면 `decode_token` 을 직접 부른다 |
| R-4 | 토큰 없이 `/attendee` 계열 → **정상 조회** | 인가 모델이 이진이다 (사람 확인). 이쪽을 안 보면 "무토큰이면 다 막힌다"가 굳는다 |

### 설계 근거 (왜 이 방안인지)

**ASGITransport 를 기본으로 쓰고 실소켓은 1개만 둔다.** 프레임 실측 결과 ASGITransport
는 h11 을 **0 프레임** 실행한다 — HTTP 바이트를 파싱하지 않고 ASGI 앱을 직접 부르기
때문이다. 전부 실소켓으로 돌리면 h11 2건을 얻는 대신 모든 테스트가 느려지고 포트·스레드
때문에 flaky 표면이 생긴다. **자주 안 돌리는 오라클은 오라클이 아니다.**

**커버리지를 프레임으로 잰다.** "이 테스트가 jinja2 를 실행한다"는 주장은 검증 없이는
믿을 수 없다 — 실제로 내 첫 시도는 `sys.modules` 를 봤고 그건 import 를 잰 것이었다.
import 는 되는데 실행은 0인 상태가 정확히 "가짜 초록"이다.
